# Fonts used by scripts/build-brand.mjs

These WOFF files are only used at build time, to turn text into vector paths for the logo and social share images.
The website itself loads Figtree and Barlow Condensed from the `@fontsource` npm packages.

| File | Family | Used for | License |
| --- | --- | --- | --- |
| roboto-condensed-600.woff | Roboto Condensed SemiBold | Logo wordmark (closest match to the original logo) | SIL Open Font License 1.1 |
| figtree-500/700/800.woff | Figtree | Social share image text | SIL Open Font License 1.1 |
| barlow-condensed-700.woff | Barlow Condensed Bold | A4S Sports share image | SIL Open Font License 1.1 |

Source: Fontsource (cdn.jsdelivr.net/fontsource), Latin subset.
